# musica assets/

Deja aquí tus canciones (`.mp3`, `.m4a`, `.ogg`, `.wav`) y aparecen solas en
el editor (**🎵 Audio → Música**), listas para ponerlas de fondo en todo el
librito o en una página. Se pueden organizar en subcarpetas.

Se listan solas en GitHub a cada subida; en la computadora:
`node herramientas/contenido.mjs`.
