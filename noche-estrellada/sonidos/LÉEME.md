# Los sonidos de la noche

Cada sonido de la fila de la cabaña tiene su carpeta propia:

| carpeta | botón |
|---|---|
| `fogata/` | Fogata |
| `grillos/` | Grillos |
| `buhos/` | Búhos |
| `aire/` | Aire |
| `bosque/` | Bosque |
| `rio/` | Río |
| `lluvia/` | Lluvia |
| `tormenta/` | Tormenta |

Deja en la carpeta uno o varios audios con el nombre que quieras. Si hay
varios, suena uno al azar. Si la carpeta está vacía, se usa el de
`audio/` con el nombre de siempre (`audio/grillos.mp3`…), y si tampoco
está, uno hecho en el momento.

Después de agregar archivos, la lista se rehace sola al subirlos (o con
`node herramientas/contenido.mjs` en tu computadora).
