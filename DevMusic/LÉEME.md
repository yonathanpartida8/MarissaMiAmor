# DevMusic/ — la música del editor

Lo que dejes aquí suena **sólo mientras editas** en «Crear librito» (nunca en
el librito). Vale `.mp3`, `.m4a`, `.ogg`, `.wav` o `.aac`.

- Una canción: suena en bucle.
- Varias: suenan una tras otra, al azar y sin repetir la misma seguida.
- Baja sola cuando suena otra cosa (una pista, un componente, la vista previa).
- Se enciende, se apaga y se le cambia el volumen en el editor: **Audio →
  Música del editor**.

Aparecen solas al subir a GitHub (o con `node herramientas/contenido.mjs`).
Si esta carpeta está vacía, el editor busca `EditorDev/MusicaDev.mp3` como antes.
