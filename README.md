# My Love Pages

El editor (**LovEdit**) y el servidor (**M.YNTHN**) para hacerle detallitos a tu amorcito: páginas con fotos,
música y animaciones, dibujitos, mensajitos, y Nuestros días juntos.

| Carpeta | Qué es |
| --- | --- |
| `EditorDev/` | el editor y la app (ábrelo en `EditorDev/index.html`; la `index.html` de la raíz sólo te manda ahí). Su guía está en `EditorDev/LÉEME.md`. |
| `servidor/` | el servidor que va en un teléfono con Termux (`servidor/LÉEME.md` y `servidor/API.md`). |
| `android/` | el APK y el plan de la app nativa (`android/NATIVA.md`). |
| `assets/`, `musica assets/`, `DevMusic/`, `vendor/` | los recursos que usa el editor (componentes, sonidos, música y three.js). |
| `publicaciones/` | lo que publica el servidor. |
| `herramientas/` | utilidades (catálogo de `assets/`, voces, etiquetas, proxy de GIFs). |

El libro de Marissa ya no está en este repositorio (queda en el historial de git). No hay que compilar nada: se sube el
repositorio a GitHub Pages y el editor funciona desde `…/EditorDev/`.
