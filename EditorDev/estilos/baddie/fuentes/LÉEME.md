# Letra del estilo Baddie

Los títulos usan una letra estilo Barbie. Por defecto es **Pacifico** (gratis,
de Google Fonts), la más parecida que se puede incluir.

Si tienes la fuente de Barbie (o cualquier otra), deja el archivo aquí
(`.woff2`, `.woff`, `.ttf` u `.otf`) y el editor la usa sola para los títulos
del estilo Baddie. Si hay varios, usa el primero en orden alfabético.
